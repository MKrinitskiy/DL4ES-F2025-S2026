# Домашнее задание №4 DL4ES 2025–2026  
## Анализ функций активации

---

## 1. Датасет и постановка задачи

В данном задании используется коллекция данных [**Beijing Multi-Site Air Quality Data**](https://ml4es.ru/links/uci-baq) (измерения качества воздуха в Пекине - доступно для скачивания по [ссылке](https://ml4es.ru/links/uci-baq)). Подробное описание коллекции данных доступно по [ссылке](BeijingAQ-README.md)

Данные содержат почасовые измерения концентраций загрязняющих веществ и метеорологических параметров на нескольких станциях мониторинга.

### Признаки (features)

Типичные признаки включают:

- концентрации загрязняющих веществ: PM2.5, PM10, SO₂, NO₂, CO, O₃;
- метеорологические параметры: температура, давление, влажность, скорость ветра;
- календарные признаки (час, день, месяц — при необходимости).

Точный состав признаков определяется в ноутбуке с решением должен быть явно описан!

### Целевая переменная

Задача — **классификация уровня загрязнения воздуха**.

Необходимо сформировать категориальную целевую переменную на основе значения концентрации PM2.5.  
Например, можно использовать дискретизацию по порогам (в решении нужно явно указать выбранные границы классов!).  

Пример возможной постановки (один из вариантов):

- Класс 0 — низкое загрязнение  
- Класс 1 — умеренное загрязнение  
- Класс 2 — высокое загрязнение  

Выбранная схема классификации должна быть строго описана в решении!

---

## 2. Формализация задачи

В решении должны быть явно указаны:

- формулировка задачи классификации для этой коллекции данных;
- описание и размерность признакового пространства;
- описание, способ кодирования целевой переменной;
- функция потерь (например, Cross-Entropy);
- метрика качества (Accuracy, F1-score, ROC-AUC и др., выбор должен быть обоснован).

---

## 3. Требования к модели

Необходимо решить задачу с помощью **глубокой полносвязной нейросети (MLP)**:

- не менее **15 скрытых слоёв**;
- архитектура должна быть одинаковой для сравнения разных функций активации (если не обосновано иное);
- корректная инициализация весов обязательна;
- использование `Batch Normalization` допускается, но должно быть явно указано, описано и обосновано.

---

## 4. Обязательные варианты функций активации

Необходимо реализовать и сравнить следующие функции активации:

1. **Sigmoid или Tanh**  
2. **ReLU**  
3. **ELU или SELU**  
4. **Swish или Mish**  

Каждый вариант должен быть обучен и проанализирован отдельно.

---

## 5. Обязательный анализ для каждого варианта

Для каждой функции активации необходимо выполнить следующие пункты.

### 5.1 Решение задачи классификации

- обучение модели;
- финальные значения функции потерь на train и validation;
- значения выбранной метрики качества;
- краткий вывод о сходимости.

---

### 5.2 Распределения активаций скрытых слоёв

Необходимо визуализировать распределения активаций скрытых слоёв в трёх стадиях обучения:

1. **Начало обучения** — сразу после инициализации;
2. **Середина обучения** — момент, когда функция потерь заметно уменьшается, но ещё не наступило насыщение;
3. **Конец обучения** — после стабилизации функции потерь.

Требуется:

- выбрать несколько характерных слоёв (например: второй, средний, предпоследний);
- построить гистограммы распределений активаций;
- проанализировать среднее и дисперсию;
- выявить насыщение (если есть).

В этом задании можно пользоваться возможностями `Tensorboard`

---

### 5.3 Распределения градиентов

Необходимо:

- визуализировать распределения градиентов функции потерь по параметрам скрытых слоёв;
- сделать это в тех же трёх стадиях обучения;
- построить норму градиентов по слоям;
- выявить эффект исчезающих или взрывающихся градиентов.

В этом задании можно пользоваться возможностями `Tensorboard`

---

### 5.4 Эволюция обучения

Для каждого варианта построить:

- график эволюции функции потерь по мере обучения (train и validation);
- график эволюции метрики качества по мере обучения;
- проанализировать устойчивость и скорость оптимизации.

---

## 6. Сравнительный анализ

В заключении необходимо:

- сравнить функции активации по:
  - скорости сходимости;
  - устойчивости оптимизации;
  - поведению активаций;
  - поведению градиентов;
  - итоговому качеству классификации;
- сделать аргументированный вывод о предпочтительной функции активации для данной задачи.

Цель задания — не только и не столько добиться высокой точности классификации, сколько продемонстрировать понимание внутренней динамики глубокой нейросети и влияния функции активации на:

- распределения активаций;
- распределения градиентов;
- устойчивость оптимизации.
